# แยกอโศก — เกมขับรถที่รถไม่ขยับ

เกมจำลองการขับรถในกรุงเทพ **ที่ตั้งใจให้ไม่สนุก**

คุณอยู่บนถนนอโศกมนตรี ห่างจากเส้นหยุดราว 25 เมตร ไฟแดงนาน 70 วินาที
ไฟเขียวปล่อยแค่ 4.5 วินาที และคนข้ามถนนกินไปอีก 2.2 วินาที
**จะชนะได้ก็ต่อเมื่อขับข้ามแยกไปได้สำเร็จ** — ซึ่งเหยียบคันเร่งรออย่างเดียวไม่มีทางสำเร็จ

ทุกๆ 16–23 วินาที รถไฟฟ้า BTS จะแล่นข้ามรางลอยฟ้าเหนือแยก แซงรถทั้งแยกในสองวินาที
พร้อมข้อความบนตัวขบวนว่า **"กรุงเทพ ชีวิตดีๆ ที่ลงตัว"**

## วิธีเล่น

ถ้าไม่ได้ก็ใช้ฟอนต์ไทยของเครื่อง)

## ทำไมต้องมุด

หัวใจของเกมอยู่ที่ข้อเดียว: **แถวรถที่หยุดนิ่งมีรูโหว่อยู่** เพราะคนขับ 30%
ทิ้งระยะห่างจากคันหน้าไว้ 4–7 เมตร (เล่นมือถือ เหม่อ ไม่รู้ตัว)
รูโหว่พวกนั้นคือทางเดียวที่จะขยับไปข้างหน้าได้ และการแทรกเข้าไปคือกริยาเดียวในเกมนี้

สิ่งที่ขัดขวางคุณ:

- **ไฟเขียวสั้นมาก** และคนข้ามถนนกินหัวไฟเขียวไปก่อน แถวรถระบายได้แค่ 1–2 คันต่อรอบ
- **รถออกจากซอย** มาแทรกข้างหน้าคุณทุกๆ 6–11 วินาที คุณจะเสียระยะเท่าที่แถวระบายได้
  → นั่งรออย่างเดียวคือลู่วิ่งสายพาน ไปไม่ถึงไหน
- **มอเตอร์ไซค์** วิ่งซอกเลนตลอดเวลา ถ้ามีมอไซค์อยู่บนเส้นแบ่งเลนที่คุณจะมุด คุณต้องรอ
- **แท็กซี่** ปาดหน้าเอาช่องที่คุณเล็งไว้ไปก่อน (16% ของทุกครั้งที่มุด)
- **รถเมล์** จอดป้ายดับเครื่อง กินเลนซ้ายทั้งเลน
- **มุดสำเร็จแล้วเลนใหม่มักจะหยุดสนิททันที** (50%) ส่วนเลนที่คุณเพิ่งออกมาก็ไปได้สวย
- **ฝ่าไฟแดงได้** แต่จะติดกลางแยก โดนปรับ 500 บาท และตำรวจจะโบกให้ถอยกลับมาหลังเส้น

ชนะแล้วเกมจะสรุปให้ว่าคุณเสียเวลาไปเท่าไร รถไม่ขยับกี่วินาที
บีบแตรไปกี่ครั้ง (ไม่มีผล) และรถไฟฟ้าแซงคุณไปกี่ขบวน แล้วบอกว่าแยกถัดไปไฟแดงกี่วินาที

## โครงสร้างโค้ด

ทั้งเกมอยู่ใน `index.html` ไฟล์เดียว ไม่มี dependency ไม่มีไฟล์ภาพหรือเสียง
กราฟิกทุกพิกเซลวาดด้วย Canvas 2D และเสียงสร้างด้วย WebAudio oscillator

เรียงตามลำดับในไฟล์:

| ส่วน | หน้าที่ |
|---|---|
| `CFG` | ค่าปรับจูนทั้งหมดรวมที่เดียว — ระยะทาง เวลาไฟ ความหนาแน่น อัตรารถแทรก |
| `TEXT` | ข้อความไทยทั้งหมด |
| `rnd()` | seeded PRNG — ตั้ง `_seed` ค่าเดิมแล้วเล่นซ้ำได้เหมือนเดิมทุกเฟรม |
| `resize()` | คำนวณ `PPM` (พิกเซลต่อเมตร) ให้ทั้งแยกพอดีจอ + เว้นแถบ HUD/ปุ่ม |
| `makeCar()` | สุ่มรถ พร้อม `s0` = ระยะห่างที่คนขับคนนั้นชอบทิ้งไว้ (คือรูโหว่ที่คุณต้องหา) |
| `updateTraffic()` | car-following แบบ IDM ย่อ + หน่วงเวลาปฏิกิริยาตอนออกตัว |
| `updatePlayer()` | ฟิสิกส์รถผู้เล่น การข้ามเส้นหยุด และการติดกลางแยก |
| `tryWeave()` | หาช่องว่างในเลนเป้าหมาย ตรวจว่ารถข้างหลังถอยให้ได้ไหม แล้วแทรก |
| `updateCutIns()` | รถออกจากซอยมาแทรกข้างหน้าผู้เล่น (ตัวที่ทำให้การรอไร้ประโยชน์) |
| `updateMotos()` `updateCross()` `updateTrain()` | มอไซค์ซอกเลน · รถทางสุขุมวิท · ขบวน BTS |
| `render()` | ถนน → รถทางขวาง → ไฟจราจร → รถ → มอไซค์ → รางลอยฟ้า → vignette → HUD |
| `step()` `loop()` | fixed timestep 1/60 วินาที + `requestAnimationFrame` |

### ปรับความยาก

แก้ที่ `CFG` ที่เดียว:

```js
GREEN: 4.5,            // ไฟเขียวยาวขึ้น = ง่ายขึ้นมาก
PED_DELAY: 2.2,        // คนข้ามถนนกินหัวไฟเขียว
CUT_IN_EVERY: [6.5, 11],   // ถี่ขึ้น = ลู่วิ่งเร็วขึ้น = ยากขึ้นมาก
SLOPPY: 0.30,          // สัดส่วนคนขับที่ทิ้งระยะห่างเยอะ = จำนวนรูโหว่
WEAVE_REACH: 8.0,      // มุดไปข้างหน้าได้ไกลสุดกี่เมตร
TAXI_STEAL: 0.16,      // โอกาสถูกปาดหน้าตอนมุด
QUEUE_AHEAD: 5,        // คิวรถข้างหน้าคุณตอนเริ่ม
```

เล่นรอบต่อไปเกมจะยากขึ้นเองเล็กน้อย (ไฟเขียวสั้นลง รถแน่นขึ้น) จนถึงรอบที่ 4
