# BANGKOK CAR RACE — ด่าน 1: แยกอโศก

เกมจำลองการขับรถในกรุงเทพ **ที่ตั้งใจให้ไม่สนุก**

คุณอยู่บนถนนอโศกมนตรี ห่างจากเส้นหยุดราว 25 เมตร ไฟแดงนาน 70 วินาที
ไฟเขียวปล่อยแค่ 4.5 วินาที และคนข้ามถนนกินไปอีก 2.2 วินาที
**จะชนะได้ก็ต่อเมื่อขับข้ามแยกไปได้สำเร็จ** — ซึ่งเหยียบคันเร่งรออย่างเดียวไม่มีทางสำเร็จ

บนสะพานลอยฟ้าเหนือแยกมีป้ายสีฟ้าแขวนอยู่ตลอดเวลาว่า
**"กรุงเทพฯ…ชีวิตดีๆ ที่ลงตัว"** และทุกๆ 16–23 วินาที รถไฟฟ้า BTS
จะแล่นผ่านเหนือป้ายนั้น แซงรถทั้งแยกในสองวินาที พร้อมข้อความเดียวกันบนตัวขบวน

## ทำไมต้องมุด

หัวใจของเกมอยู่ที่ข้อเดียว: **แถวรถที่หยุดนิ่งมีรูโหว่อยู่** เพราะคนขับ 30%
ทิ้งระยะห่างจากคันหน้าไว้ 4–7 เมตร (เล่นมือถือ เหม่อ ไม่รู้ตัว)
รูโหว่พวกนั้นคือทางเดียวที่จะขยับไปข้างหน้าได้ และการแทรกเข้าไปคือกริยาเดียวในเกมนี้

สิ่งที่ขัดขวางคุณ:

- **ไฟเขียวสั้นมาก** และคนข้ามถนนกินหัวไฟเขียวไปก่อน แถวรถระบายได้แค่ 1–2 คันต่อรอบ
- **รถออกจากซอย** มาแทรกข้างหน้าคุณทุกๆ 6–11 วินาที คุณจะเสียระยะเท่าที่แถวระบายได้
  → นั่งรออย่างเดียวคือลู่วิ่งสายพาน ไปไม่ถึงไหน
- **มอเตอร์ไซค์** วิ่งซอกเลนตลอดเวลา ถ้ามีมอไซค์อยู่บนเส้นแบ่งเลนที่คุณจะมุด คุณต้องรอ
- **แท็กซี่** ปาดหน้าเอาช่องที่คุณเล็งไว้ไปก่อน (16% ของทุกครั้งที่มุด)
- **รถเมล์** จอดป้ายดับเครื่อง กินเลนซ้ายทั้งเลน
- **มุดสำเร็จแล้วเลนใหม่มักจะหยุดสนิททันที** (50%) ส่วนเลนที่คุณเพิ่งออกมาก็ไปได้สวย
- **ฝ่าไฟแดงได้** แต่จะติดกลางแยก โดนปรับ 500 บาท และตำรวจจะโบกให้ถอยกลับมาหลังเส้น
- **ป้ายนับถอยหลังข้างเสาไฟ** จะโชว์ตัวเลขแค่ 15 วินาทีสุดท้ายของไฟแดง
  ก่อนนั้นขึ้น `--` เหมือนของจริง — คุณจะไม่รู้ว่าต้องรออีกนานแค่ไหน

ชนะแล้วเกมจะสรุปให้ว่าคุณเสียเวลาไปเท่าไร รถไม่ขยับกี่วินาที
บีบแตรไปกี่ครั้ง (ไม่มีผล) และรถไฟฟ้าแซงคุณไปกี่ขบวน แล้วบอกว่าแยกถัดไปไฟแดงกี่วินาที

## โครงสร้างโค้ด

ทั้งเกมอยู่ใน `index.html` ไฟล์เดียว ไม่มี dependency ไม่มีไฟล์ภาพหรือเสียง
กราฟิกทุกพิกเซลวาดด้วย Canvas 2D และเสียงสร้างด้วย WebAudio oscillator

เรียงตามลำดับในไฟล์:

| ส่วน | หน้าที่ |
|---|---|
| `CFG` | ค่าปรับจูนทั้งหมดรวมที่เดียว — ระยะทาง เวลาไฟ ความหนาแน่น อัตรารถแทรก |
| `TEXT` | ข้อความไทยทั้งหมด |
| `rnd()` | seeded PRNG — ตั้ง `_seed` ค่าเดิมแล้วเล่นซ้ำได้เหมือนเดิมทุกเฟรม |
| `resize()` | คำนวณ `PPM` (พิกเซลต่อเมตร) ให้ทั้งแยกพอดีจอ + เว้นแถบ HUD/ปุ่ม |
| `makeCar()` | สุ่มรถ พร้อม `s0` = ระยะห่างที่คนขับคนนั้นชอบทิ้งไว้ (คือรูโหว่ที่คุณต้องหา) |
| `updateTraffic()` | car-following แบบ IDM ย่อ + หน่วงเวลาปฏิกิริยาตอนออกตัว |
| `updatePlayer()` | ฟิสิกส์รถผู้เล่น การข้ามเส้นหยุด และการติดกลางแยก |
| `tryWeave()` | หาช่องว่างในเลนเป้าหมาย ตรวจว่ารถข้างหลังถอยให้ได้ไหม แล้วแทรก |
| `updateCutIns()` | รถออกจากซอยมาแทรกข้างหน้าผู้เล่น (ตัวที่ทำให้การรอไร้ประโยชน์) |
| `updateMotos()` `updateCross()` `updateTrain()` | มอไซค์ซอกเลน · รถทางสุขุมวิท · ขบวน BTS |
| `drawBanner()` | ป้าย "กรุงเทพฯ…ชีวิตดีๆ ที่ลงตัว" บนสะพาน วาดทับขบวนรถไฟเสมอ |
| `render()` | ถนน → รถทางขวาง → ไฟจราจร → รถ → มอไซค์ → รางลอยฟ้า+ป้าย → vignette → HUD |
| `step()` `loop()` | fixed timestep 1/60 วินาที + `requestAnimationFrame` |

### ปรับความยาก

แก้ที่ `CFG` ที่เดียว:

```js
GREEN: 4.5,            // ไฟเขียวยาวขึ้น = ง่ายขึ้นมาก
PED_DELAY: 2.2,        // คนข้ามถนนกินหัวไฟเขียว
CUT_IN_EVERY: [6.5, 11],   // ถี่ขึ้น = ลู่วิ่งเร็วขึ้น = ยากขึ้นมาก
SLOPPY: 0.30,          // สัดส่วนคนขับที่ทิ้งระยะห่างเยอะ = จำนวนรูโหว่
WEAVE_REACH: 8.0,      // มุดไปข้างหน้าได้ไกลสุดกี่เมตร
TAXI_STEAL: 0.16,      // โอกาสถูกปาดหน้าตอนมุด
QUEUE_AHEAD: 5,        // คิวรถข้างหน้าคุณตอนเริ่ม
```

เล่นรอบต่อไปเกมจะยากขึ้นเองเล็กน้อย (ไฟเขียวสั้นลง รถแน่นขึ้น) จนถึงรอบที่ 4

## สิ่งที่ช่วยให้เล็งได้จริง

- **เงาปลายทาง** — จำลองวิถีกระสุนด้วยกติกาเดียวกับตอนยิงจริง แล้ววาดเงาไว้ตรงช่องที่มันจะไปเกาะ
  ไม่ต้องเดาว่าขั้นบันไดจะรับนัดนี้ตรงไหน
- **เส้นประสีชมพูพาดแถว** — แถวนั้นไม่มีอะไรให้ชน ยิงไปก็ไหลออกนอกสนามเปล่าๆ
- **แถบสีจาง ๆ คลุมแถว** — แถวนั้นมีนัดเก่าค้างอยู่ ยิงซ้ำไม่ได้ (ปลายลำกล้องจะเปลี่ยนเป็นสีชมพูด้วย)
- **ก้อนเดียวกัน = สีเดียวกัน** เพราะเงื่อนไขเคลียร์คิดเป็น "ก้อนที่ต่อกัน" ต้องมองออกว่าอันไหนเป็นอันเดียวกัน
- **กรอบ + จุดไข่ปลา** บนก้อนที่ใกล้เต็ม บอกว่าเหลือขาดอีกกี่ช่อง
- **แท่งปืนสูงเท่าช่วงแถวที่นัดนี้จะออกจริง** — กระสุนแท่งตั้งตอนจ่อล่างสุดจะถูกดันขึ้น แท่งปืนบอกให้เห็นเลย
- **แถบบนสุดของสนาม** นับถอยหลังก่อนกำแพงขยับอีกช่อง และกำแพงเลื่อนแบบลื่น ไม่วาร์ปทีละช่อง
- **ยิ่งก้อนใกล้เส้นแดง เส้นยิ่งสว่างและมีเสียงหัวใจเต้นถี่ขึ้น** ไม่ใช่รอจนเหลือก้าวเดียวค่อยเตือน

## ไอเทม

ได้จากการเล่นเก่ง ไม่ได้สุ่มแจก และถือได้ทีละชิ้น กด <kbd>V</kbd> หรือปุ่ม **ใช้** เพื่อยิง

- **ระเบิด** 💣 — คอมโบ x3 ล้างบล็อก 3×3 ตรงจุดที่ชน
- **เลเซอร์** ⚡ — คอมโบ x5 ทะลุล้างทั้งแถวตั้งแต่ปากกระบอกจนสุดขอบขวา

ทั้งคู่ไม่เติมช่อง มีแต่ล้าง เอาไว้แก้ตอนก้อนจ่อเส้นแดงแล้วเติมไม่ทัน

## เงื่อนไขการระเบิด (สำคัญ)

**ก้อนแต่ละก้อนมีตัวตนของตัวเองและคิดกรอบของตัวเองแยกกัน** เติมกรอบเดิมของก้อนไหนจนเต็ม
ก้อนนั้นระเบิด ไม่สนว่ามีบล็อกอื่นมาต่อติดอยู่ข้าง ๆ หรือเปล่า

เดิมเงื่อนไขคือ "กลุ่มบล็อกที่ต่อกันต้องเป็นสี่เหลี่ยมทึบพอดี" ซึ่งพังสองทาง

- ยิงพลาดไปเกาะ**นอกกรอบ**ก้อนแค่ช่องเดียว กลุ่มนั้นจะไม่มีวันเป็นสี่เหลี่ยมอีกเลย
  = ก้อนนั้นตายถาวร ลอยไปชนเส้นแดงแน่นอน (ทดสอบยืนยันแล้ว)
- ก้อนสองก้อนที่โดนบล็อกของผู้เล่นเชื่อมติดกันก็ตายถาวรทั้งคู่ด้วยเหตุผลเดียวกัน

ตอนนี้บล็อกที่ยิงไปเกาะนอกกรอบเป็นแค่ "นั่งร้าน" พอก้อนระเบิดมันจะหลุดตามไปด้วย
และเศษที่ลอยเดี่ยวไม่ติดอะไรเลยจะร่วงทิ้งไปเอง ไม่มีขยะค้างถาวรในสนามอีก

(ผู้เล่นยังก่อสี่เหลี่ยมทึบขึ้นมาเองล้วน ๆ เพื่อเก็บคะแนนได้เหมือนเดิม)

## กติกาที่ควรรู้

- กระสุนหลายช่อง **แตกตัวได้** — ช่องที่ชนเกาะติดตรงนั้น ช่องที่ยังโปร่งไหลต่อไปเอง
  แท่งตั้งจึงยิงเข้าขั้นบันไดนัดเดียวแล้วเติมได้หลายระดับความลึกพร้อมกัน
- กระสุนสุ่มมาเป็น **ถุง** — ครบทั้ง 6 แบบก่อนแล้วค่อยวนใหม่ ไม่มีเจอ "จุด" ติดกันห้านัด
- เคลียร์ได้ 1 ครั้ง = **ถ่วงกำแพงให้อีก 1 ช่อง** เล่นเก่งยิ่งยืดเกมได้เอง
- **เคลียร์ติดกันภายใน 4 วินาที = คอมโบ** คูณคะแนนขึ้นเรื่อยๆ จนกว่าจะขาดช่วง
- **ก้อนใหญ่คุ้มกว่าก้อนเล็กแบบทวีคูณ** — ทุกช่องที่ใหญ่ขึ้นเพิ่มคะแนนต่อช่องอีก 10%
  ก้อน 4×4 ได้ 352 ส่วนก้อน 2×2 สี่ก้อนได้แค่ 160 จะรีบเก็บหรือปล่อยให้โตก่อนก็เป็นการตัดสินใจ
- **นัดเดียวปิดหลายก้อนพร้อมกัน** = โบนัสเพิ่ม 50% ต่อก้อนที่เกินมา (DOUBLE / TRIPLE KILL)
- เคลียร์โดยไม่มีกระสุนตกหล่นเลยตั้งแต่ครั้งก่อน = โบนัส **PERFECT** (+50% ของคะแนนตานั้น)
- ทุก 5 เลเวลเจอ **เวฟใหญ่** — ก้อนสูง 4-6 แถวและชิดกันกว่าปกติ มีเตือนล่วงหน้าก่อนมาถึง
- ยิ่งเลเวลสูง กำแพงยิ่งเลื่อนเร็ว **และ** ก้อนอัดแน่นขึ้นทั้งแนวตั้งและแนวนอน
- จบเกมมีสรุปให้ว่าระเบิดไปกี่ก้อน ได้ PERFECT กี่ครั้ง คอมโบสูงสุดเท่าไหร่ ก้อนใหญ่สุดกี่คูณกี่
  และยิงโดนเป้ากี่เปอร์เซ็นต์ พร้อมสถิติสะสมข้ามรอบ (เล่นมากี่รอบ ระเบิดรวมกี่ก้อน)

## อยากให้ก้อนถี่กว่านี้ (หรือเบากว่านี้)

ก้อนจะไล่วางเต็มความสูงของแถบเสมอ ปรับความหนาแน่นที่สองค่านี้ใน `block-shooter.html`

```js
var VGAP = 3;              // เว้นกี่แถวระหว่างก้อนบน-ล่างในแถบเดียวกัน (บวกสุ่มอีก 0-1)
var GAPW = NARROW ? 5 : 6; // เว้นกี่คอลัมน์ระหว่างแถบ
```

ยิ่งน้อยยิ่งแน่น ทั้งคู่แคบลงเองตามเลเวล (`MIN_VGAP` กับ `MIN_GAPW` คือเพดานล่าง)
ที่เลเวล 1 ตอนนี้ได้ก้อนราว 3.3 ก้อนต่อแถบ (เต็มความสูงราว 48%) ไต่ขึ้นไปถึง 4.6 ก้อน (68%) ที่เลเวล 20

## หมายเหตุทางเทคนิค

- จอแคบกว่า 720px จะย่อสนามเหลือ 16×18 (ปกติ 20×30) ไม่งั้นช่องจะเหลือ ~11px จนมองไม่เห็น
- บล็อกทุกช่องอบเป็นสไปรต์ต่อสีไว้ล่วงหน้า แล้ว `drawImage` เอา — เร็วกว่าวาด
  gradient + `shadowBlur` สดๆ ทุกเฟรมประมาณ 5-6 เท่า (วัดที่สนามเต็ม 425 ช่อง: 4.1ms → 0.7ms ต่อเฟรม
  ทั้งที่เวอร์ชันใหม่ยังวาดกรอบช่วยเล็ง เงาปลายทาง และกำแพงเลื่อนลื่นเพิ่มเข้าไปด้วย)
- เพลงประกอบเป็นเบสไลน์ที่สังเคราะห์จาก oscillator ตัวเดียวกับ SFX ไม่มีไฟล์เสียงให้โหลด
  จังหวะผูกกับความเร็วกำแพง ยิ่งเลเวลสูงยิ่งเร่ง (ปิดได้ที่ปุ่มลำโพง)
- เคารพ `prefers-reduced-motion` — ปิดสั่นจอ ลดแฟลชและเศษระเบิด
- พอสอัตโนมัติเมื่อสลับแท็บหรือหน้าต่างเสียโฟกัส
